# PONG - Retro Edition

Klasická arkádová hra Pong ve stylu 80. let s minimalistickým designem.

## Ovládání

- **W** - pohyb pálky nahoru
- **S** - pohyb pálky dolů
- **MEZERNÍK** - reset hry

## Jak hrát

Otevřete soubor `index.html` ve webovém prohlížeči. Hra začne automaticky.

Cíl: Odražejte míček a získejte více bodů než počítač!

## Features

- Retro minimalistický design (zelená na černé)
- Plynulá animace
- Jednoduchá AI protivník
- Responzivní ovládání
- Sledování skóre

## Technologie

- HTML5 Canvas
- Vanilla JavaScript
- CSS3
