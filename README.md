# PONG - Retro Edition

Klasická arkádová hra Pong ve stylu 80. let s minimalistickým designem.

## Ovládání

- **W** - pohyb pálky nahoru
- **S** - pohyb pálky dolů
- **MEZERNÍK** - reset hry
- **ESC** - otevřít menu obtížnosti

## Jak hrát

1. Otevřete soubor `index.html` ve webovém prohlížeči
2. Vyberte obtížnost (Lehká, Střední, Těžká)
3. Odražejte míček a získejte více bodů než počítač!

## Features

### Herní mechaniky
- **Postupné zrychlování** - míček se zrychluje při každém odrazu až do maximální rychlosti
- **Tři úrovně obtížnosti**:
  - **Lehká** - AI dělá hodně chyb, pomalá rychlost, mírné zrychlování
  - **Střední** - Vyvážená obtížnost pro zábavnou hru
  - **Těžká** - Rychlá AI s minimálními chybami, rychlé zrychlování

### AI chování
- AI občas chybuje a nereaguje (náhodná nepozornost)
- Nepřesné zaměřování (není dokonalá)
- Obtížnost ovlivňuje rychlost AI a míru chyb

### Design
- Retro minimalistický design (zelená na černé)
- Neonový svítící efekt
- Plynulá animace pomocí Canvas API
- Responzivní ovládání
- Sledování skóre

## Technologie

- HTML5 Canvas
- Vanilla JavaScript
- CSS3
